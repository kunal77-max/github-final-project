# Contributing Guidelines

Thank you for your interest in contributing to the Simple Interest Calculator project!

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to Contribute

1. Fork this repository.
2. Clone your fork to your local machine.
3. Create a new branch for your changes.
4. Make your changes and test them.
5. Commit your changes with a clear and descriptive commit message.
6. Push your branch to your forked repository.
7. Open a pull request describing your changes.

## Reporting Bugs

- Check whether the issue has already been reported.
- Clearly describe the problem and steps to reproduce it.
- Include expected and actual results.
- Provide relevant error messages or screenshots when possible.

## Suggesting Enhancements

- Explain the proposed enhancement.
- Describe why it would be useful.
- Provide examples where possible.

## Documentation Improvements

Improvements to the README, code comments, installation instructions, and other documentation are welcome.

## Code Contributions

- Keep the code simple and readable.
- Follow consistent naming and formatting conventions.
- Test your changes before submitting them.
- Ensure that your changes do not break existing functionality.

## Pull Request Guidelines

- Provide a clear description of your changes.
- Reference related issues when applicable.
- Keep pull requests focused on a specific improvement.
- Respond constructively to review feedback.

Thank you for helping improve this project!
