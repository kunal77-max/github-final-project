# Simple Interest Calculator

## Description
The Simple Interest Calculator is a simple project that calculates the interest earned or payable on a principal amount over a specified period at a given annual interest rate.

## Formula
Simple Interest is calculated using the following formula:

**Simple Interest = (Principal × Rate × Time) / 100**

Where:
- **Principal (P):** The initial amount of money.
- **Rate (R):** The annual rate of interest in percentage.
- **Time (T):** The time period in years.

## Features
- Accepts the principal amount from the user.
- Accepts the annual rate of interest.
- Accepts the time period in years.
- Calculates and displays the simple interest.
- Easy to use and understand.

## Technologies Used
- Bash scripting
- Git
- GitHub

## Example
Suppose:
- Principal = 1000
- Rate = 5%
- Time = 2 years

Calculation:

Simple Interest = (1000 × 5 × 2) / 100 = 100

**Result: Simple Interest = 100**

## How to Run
1. Clone or download this repository.
2. Open a terminal in the project directory.
3. Run the script using:

   ```bash
   bash simple-interest.sh
   ```

4. Enter the principal amount, rate of interest, and time period when prompted.
