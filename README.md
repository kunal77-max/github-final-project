# GitHub Final Project

## Project Description
This project demonstrates the use of GitHub and Git CLI, including repository documentation, open-source contribution guidelines, shell scripting, branching, merging, and pull requests.

## Project Objectives
- Create and manage a public GitHub repository.
- Add an Apache 2.0 license.
- Establish a code of conduct and contribution guidelines.
- Write a Bash script to calculate simple interest.
- Practice Git commands for forking, branching, merging, and pull requests.

## Technologies Used
- Git
- GitHub
- Bash

## Project Files
- `README.md` — Project overview and documentation.
- `LICENSE` — Apache 2.0 license.
- `CODE_OF_CONDUCT.md` — Community behavior guidelines.
- `CONTRIBUTING.md` — Contribution instructions.
- `simple-interest.sh` — Simple interest calculator.
